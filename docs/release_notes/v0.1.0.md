# `new_robot_code` 首版发布说明 `v0.1.0`

## 1. 发布定位

`v0.1.0` 是当前应用层工程的首版仓库化发布，目标是：

1. 形成可独立协作的应用仓库骨架。
2. 固化当前正式启动链与主要控制任务。
3. 固化当前文档、构建入口、调试入口和本机预设模板。

本版本不追求“全部功能完全定型”，重点是把当前已经可运行、可构建、可继续开发的正式链收敛成稳定仓库基线。

## 3. 当前构建与调试基线

1. 顶层目标名：`robot_project`
2. ELF 产物名：`robot_project.elf`
3. 烧录目标名：`flash.jlink.target = "robot_project"`
4. 当前默认板级：`rm-a-board`
5. 当前依赖同级 `oh-my-robot-framework`

## 4. 已知限制

1. 当前仓库仍依赖同级 `oh-my-robot-framework`，不是自包含仓库。
2. `om_preset.lua` 为本机私有文件，不随仓库提交。
3. 当前正式控制链与仿真文档已对齐，但后续参数、姿态表、动作时序仍可能继续迭代。
4. `app/task/test/` 中的测试任务保留在仓库中，属于正式源码的一部分，不等于发布功能入口。

## 5. 建议的后续工作

1. 根据协作需要补 GitHub PR 模板、Issue 模板和 CI。
2. 根据团队实际环境补充 `.vscode/tasks.json` 或共享构建任务。
3. 若后续要降低环境耦合，单独设计 `oh-my-robot-framework` 的版本固定方式。
